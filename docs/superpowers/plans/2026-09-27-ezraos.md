# EzraOS Portfolio Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild ezrabrilliant.com as "EzraOS" — a small operating system whose pre-installed apps (Bot, Monitor, Market, Kasir, Files, Terminal, Petak Umpet) are Ezra's real product genres filled with his real production data.

**Architecture:** A single window-manager state store (plain TS reducer + React context — no zustand) owns open/minimized/position/z-order state; a shared `WindowFrame` component renders chrome (drag, focus, close/minimize) around one lazy-loaded component per app under `src/apps/`. All app content flows from `src/config/portfolio.ts` through typed selectors in `src/config/os-content.ts`, so app components stay dumb. Boot, desktop, dock, and menu bar live under `src/os/`; design tokens in one `tokens.css`.

**Tech Stack:** React 19, Vite 7, Tailwind 4, TypeScript (strict), GSAP ^3.13 (framer-motion removed), @emailjs/browser (kept, inside Kasir), Vitest + @testing-library/react (new), Express/Docker/Caddy deployment (unchanged).

**Spec:** `docs/superpowers/specs/2026-09-27-portfolio-redesign-design.md` (authoritative). Validated interaction reference: `docs/superpowers/specs/2026-09-27-mockup-ezra-os.html` (throwaway single-file mockup — translate its proven behavior into React, never copy-paste it).

## Global Constraints

Every task's requirements implicitly include this section.

- **Branch:** all work happens on `redesign/ezraos` (already created and checked out).
- **Colour tokens (spec §4, exact):** `desk #1E2333`, `paper #F4F1E8`, `ink #1D1B16`, `amber #FFB300`. Any added text colour must pass WCAG AA ≥ 4.5:1 computed with the WCAG 2.1 relative-luminance formula before it ships.
- **Type:** IBM Plex Mono for OS chrome (menu bar, title bars, terminal, boot); IBM Plex Sans for app content; tabular figures for numbers. Retired: Archivo, Spline Sans Mono, Space Grotesk, Plus Jakarta Sans, JetBrains Mono.
- **BANNED as headline or metric anywhere (spec, locked):** "UAT 73/73", SUS scores, infra cost ($/month), VPS size ("1 GB"), "served from my own VPS", any framing of self-hosting as cheapness. Also banned: invented stats ("500+ learning hours").
- **Lead metrics, strongest first (locked order):** ① 2,700+ paid orders / 370+ buyers — Orbit Store; ② 3.1M visits, 2.6K peak CCU — Petak Umpet; ③ ~14.5k requests/day — GTID; ④ 1,000+ members — Ezra Bot; ⑤ 41% faster transactions — POS Monosuko.
- **Banned generic tells:** no gradients/glows/glass, no single-word colour accent in headlines, no ALL-CAPS tracked eyebrow labels, no `01/02/03` markers, no middle-dot meta strings, no `→` after links, no uniform rounded cards, no uniform fade-ups. Tech stacks are plain sentences, never badge clouds.
- **Motion:** GSAP only (`gsap@^3.13`); `framer-motion` is removed. Boot is the single orchestrated sequence (~2 s, skippable by any key/click). Window snaps well under 200 ms. `prefers-reduced-motion`: boot skipped entirely, snaps instant, Petak Umpet icon does not flee.
- **The page itself never scrolls** (`html,body{overflow:hidden}`); only window bodies scroll.
- **Keyboard:** every interactive element operable and visibly focused; `Esc` closes the focused window; window-cycle shortcut is **Ctrl+`** (backtick — fixed here; not Alt+Tab/Ctrl+Tab), listed in Terminal `help` and the About window; Tab is contained inside the focused window; focus returns to the launching icon/dock entry on close.
- **Phone-OS mode:** `(max-width: 767.98px)` or `(hover: none) and (pointer: coarse)` — full-screen apps with a back control, no dragging, icon grid home screen, minimum supported width 360 px.
- **All windows are DOM**; `index.html` carries a `<noscript>` block with the bio, the five lead metrics, and the project list.
- **Boot `/projects` count is derived from `portfolio.ts`** (currently 12 entries), never hard-coded.
- **Kasir:** all items free (`Rp 0`); receipt downloadable as client-side `.txt` (no PDF library); EmailJS survives only as the "Kirim pesan" order item.
- **Data values** (years, metrics, statuses) come from existing `portfolio.ts`/spec values only — never invent one. OS/UI copy is design-owned.
- **Keep:** React 19, Vite 7, Tailwind 4, TS, `src/config/portfolio.ts` as single content source, `src/lib/cloudinary.ts`, `server.js` + Dockerfile/Caddy (deployment untouched). Old section components get **deleted** (Task 15), never themed.
- **PageSpeed ≥ 95:** IBM Plex preloaded async (weights 400/500/600 only), GSAP imported tree-shaken (`import { gsap } from 'gsap'`, core only), every app code-split via `React.lazy`.
- **Commits:** end every commit message with the line `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- **Tests:** fast logic tests (jsdom), no pixel assertions. Run with `npm test` (= `vitest run`).

## Review Focus

The five failure modes the spec implies but leaves silent, most likely to bite first. Each line's pinning test lives in the owning task's steps (test name given).

1. **EmailJS send fails** (missing `VITE_EMAILJS_*` env, offline, service error) → the receipt must print `MESSAGE FAILED` plus the direct email as fallback, never a false `MESSAGE SENT`. → Task 12, test `prints MESSAGE FAILED when emailjs.send rejects`.
2. **Order with zero items selected** → the Order button is disabled, so an empty receipt can never print. → Task 12, test `Order stays disabled until an item is selected`.
3. **Terminal input with stray whitespace or capitals** (`"  HELP  "`) → runs the command; only genuinely unknown words get `command not found — try help`. → Task 11, test `trims and lowercases input before matching`.
4. **A window dragged toward an edge or a shrinking viewport** → the clamp must always keep ≥ 80 px of the window horizontally visible and the title bar inside the desk (y ∈ [0, deskH−30]), or the window becomes unrecoverable. → Task 3, test `clampToDesk keeps the title bar reachable`.
5. **A `case:` window opened for a slug that does not exist in `portfolio.ts`** (stale Bot chip, mistyped id) → renders a calm "file not found" body instead of crashing the whole OS. → Task 8, test `CaseWindow renders file-not-found for an unknown slug`.

```ts
/** jsdom has no matchMedia. Install a stub; `matching` entries match by substring of the query. */
export function mockMatchMedia(matching: string[] = []): void {
  window.matchMedia = ((query: string) =>
    ({
      matches: matching.some((m) => query.includes(m)),
      media: query,
      onchange: null,
      addListener: () => {},
      removeListener: () => {},
      addEventListener: () => {},
      removeEventListener: () => {},
      dispatchEvent: () => false,
    }) as MediaQueryList) as typeof window.matchMedia;
}
```

```ts
export type WindowId = string;

export interface WindowRecord {
  id: WindowId;
  x: number;
  y: number;
  z: number;
  minimized: boolean;
}

export interface WMState {
  windows: WindowRecord[];
  nextZ: number;
}

export type WMAction =
  | { type: 'OPEN'; id: WindowId; x: number; y: number }
  | { type: 'CLOSE'; id: WindowId }
  | { type: 'MINIMIZE'; id: WindowId }
  | { type: 'RESTORE'; id: WindowId }
  | { type: 'FOCUS'; id: WindowId }
  | { type: 'MOVE'; id: WindowId; x: number; y: number }
  | { type: 'CYCLE' };

export const initialWM: WMState = { windows: [], nextZ: 1 };

export function focusedId(state: WMState): WindowId | null {
  let best: WindowRecord | null = null;
  for (const w of state.windows) {
    if (!w.minimized && (!best || w.z > best.z)) best = w;
  }
  return best ? best.id : null;
}

/** New windows cascade from the top-left of the free area; wraps after 8. */
export function cascadePosition(openCount: number): { x: number; y: number } {
  const n = openCount % 8;
  return { x: 48 + n * 32, y: 24 + n * 28 };
}

/** ≥80px of the window stays horizontally visible; the title bar (30px) stays inside the desk. */
export function clampToDesk(x: number, y: number, winWidth: number, deskW: number, deskH: number): { x: number; y: number } {
  return {
    x: Math.round(Math.min(Math.max(x, -(winWidth - 80)), deskW - 80)),
    y: Math.round(Math.min(Math.max(y, 0), deskH - 30)),
  };
}

function raise(state: WMState, id: WindowId, unminimize: boolean): WMState {
  return {
    nextZ: state.nextZ + 1,
    windows: state.windows.map((w) =>
      w.id === id ? { ...w, z: state.nextZ, minimized: unminimize ? false : w.minimized } : w,
    ),
  };
}

export function wmReducer(state: WMState, action: WMAction): WMState {
  switch (action.type) {
    case 'OPEN': {
      if (state.windows.some((w) => w.id === action.id)) return raise(state, action.id, true);
      return {
        nextZ: state.nextZ + 1,
        windows: [...state.windows, { id: action.id, x: action.x, y: action.y, z: state.nextZ, minimized: false }],
      };
    }
    case 'CLOSE':
      return { ...state, windows: state.windows.filter((w) => w.id !== action.id) };
    case 'MINIMIZE':
      return {
        ...state,
        windows: state.windows.map((w) => (w.id === action.id ? { ...w, minimized: true } : w)),
      };
    case 'RESTORE':
    case 'FOCUS':
      return raise(state, action.id, true);
    case 'MOVE':
      return {
        ...state,
        windows: state.windows.map((w) => (w.id === action.id ? { ...w, x: action.x, y: action.y } : w)),
      };
    case 'CYCLE': {
      const visible = state.windows.filter((w) => !w.minimized);
      if (visible.length < 2) return state;
      const backMost = visible.reduce((a, b) => (a.z < b.z ? a : b));
      return raise(state, backMost.id, false);
    }
  }
}
```

```ts
export const TOKENS = {
  desk: '#1E2333',   // wallpaper, deep ink-indigo
  paper: '#F4F1E8',  // window body
  ink: '#1D1B16',    // text, borders, inactive title bars
  amber: '#FFB300',  // active title bar, boot log text
  muted: '#5E5A50',  // secondary text on paper/card
  card: '#FFFDF7',   // raised surfaces inside windows
  rule: '#D9D3C2',   // hairlines, table headers (never carries text alone)
  bootbg: '#14121A', // boot screen background
} as const;

/** WCAG 2.1 relative luminance + contrast ratio. */
function channel(v: number): number {
  const c = v / 255;
  return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}
function luminance(hex: string): number {
  const n = parseInt(hex.slice(1), 16);
  return 0.2126 * channel((n >> 16) & 255) + 0.7152 * channel((n >> 8) & 255) + 0.0722 * channel(n & 255);
}
export function contrastRatio(a: string, b: string): number {
  const [l1, l2] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (l1 + 0.05) / (l2 + 0.05);
}
```

```ts
import { gsap } from 'gsap';

export function prefersReducedMotion(): boolean {
  return typeof window !== 'undefined'
    && typeof window.matchMedia === 'function'
    && window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}

/** Window-open snap: scale/opacity, 150ms. Instant under reduced motion. */
export function snapIn(el: Element): void {
  if (prefersReducedMotion()) {
    gsap.set(el, { scale: 1, opacity: 1 });
    return;
  }
  gsap.fromTo(el, { scale: 0.94, opacity: 0 }, { scale: 1, opacity: 1, duration: 0.15, ease: 'power2.out' });
}
```

```tsx
import { createContext, useCallback, useContext, useMemo, useReducer, useRef, type ReactNode } from 'react';
import { cascadePosition, initialWM, wmReducer, type WindowId, type WMState } from './window-manager';

export interface WM {
  state: WMState;
  open: (id: WindowId, opener?: HTMLElement | null) => void;
  close: (id: WindowId) => void;
  minimize: (id: WindowId) => void;
  restore: (id: WindowId) => void;
  focus: (id: WindowId) => void;
  move: (id: WindowId, x: number, y: number) => void;
  cycle: () => void;
}

const WMContext = createContext<WM | null>(null);

export function WindowManagerProvider({ children }: { children: ReactNode }) {
  const [state, dispatch] = useReducer(wmReducer, initialWM);
  const openers = useRef(new Map<WindowId, HTMLElement>());
  const countRef = useRef(0);
  countRef.current = state.windows.length;

  const open = useCallback((id: WindowId, opener?: HTMLElement | null) => {
    if (opener) openers.current.set(id, opener);
    const pos = cascadePosition(countRef.current);
    dispatch({ type: 'OPEN', id, x: pos.x, y: pos.y });
  }, []);

  const close = useCallback((id: WindowId) => {
    dispatch({ type: 'CLOSE', id });
    const opener = openers.current.get(id);
    openers.current.delete(id);
    if (opener && opener.isConnected) {
      requestAnimationFrame(() => opener.focus({ preventScroll: true }));
    }
  }, []);

  const api = useMemo<WM>(() => ({
    state,
    open,
    close,
    minimize: (id) => dispatch({ type: 'MINIMIZE', id }),
    restore: (id) => dispatch({ type: 'RESTORE', id }),
    focus: (id) => dispatch({ type: 'FOCUS', id }),
    move: (id, x, y) => dispatch({ type: 'MOVE', id, x, y }),
    cycle: () => dispatch({ type: 'CYCLE' }),
  }), [state, open, close]);

  return <WMContext.Provider value={api}>{children}</WMContext.Provider>;
}

export function useWM(): WM {
  const wm = useContext(WMContext);
  if (!wm) throw new Error('useWM must be used inside <WindowManagerProvider>');
  return wm;
}
```

Note: `countRef` exists because `open` must read the current window count without re-creating the callback each render; `OPEN` of an already-open id ignores x/y (the reducer restores instead), so a momentarily stale count is harmless.

- [ ] **Step 6: Implement `src/os/WindowFrame.tsx`**

```tsx
import { useEffect, useLayoutEffect, useRef, type KeyboardEvent, type PointerEvent, type ReactNode } from 'react';
import { clampToDesk, type WindowId } from './window-manager';
import { useWM } from './WindowManagerContext';
import { snapIn } from '@/lib/motion';

export interface WindowFrameProps {
  id: WindowId;
  title: string;
  width: number;
  height?: number;
  x: number;
  y: number;
  z: number;
  focused: boolean;
  minimized: boolean;
  children: ReactNode;
}

const FOCUSABLE =
  'a[href], button:not([disabled]), input:not([disabled]), textarea:not([disabled]), select:not([disabled]), [tabindex]:not([tabindex="-1"])';

function containTab(e: KeyboardEvent, root: HTMLElement) {
  const items = Array.from(root.querySelectorAll<HTMLElement>(FOCUSABLE));
  if (items.length === 0) return;
  const first = items[0];
  const last = items[items.length - 1];
  if (e.shiftKey && (document.activeElement === first || document.activeElement === root)) {
    e.preventDefault();
    last.focus();
  } else if (!e.shiftKey && document.activeElement === last) {
    e.preventDefault();
    first.focus();
  }
}

export function WindowFrame({ id, title, width, height, x, y, z, focused, minimized, children }: WindowFrameProps) {
  const wm = useWM();
  const ref = useRef<HTMLElement>(null);
  const labelId = `wt-${id.replace(/[^a-z0-9]/gi, '-')}`;

  useEffect(() => {
    if (ref.current) snapIn(ref.current);
  }, []);

  // clamp into the desk on mount (window may cascade past a small viewport)
  useLayoutEffect(() => {
    const el = ref.current;
    const desk = el?.offsetParent as HTMLElement | null;
    if (!el || !desk) return;
    const p = clampToDesk(x, y, el.offsetWidth, desk.clientWidth, desk.clientHeight);
    if (p.x !== x || p.y !== y) wm.move(id, p.x, p.y);
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  // when this window becomes focused and focus is elsewhere, move DOM focus into it
  useEffect(() => {
    const el = ref.current;
    if (focused && el && !el.contains(document.activeElement)) {
      el.focus({ preventScroll: true });
    }
  }, [focused]);

  const onKeyDown = (e: KeyboardEvent) => {
    if (e.key === 'Escape') {
      e.stopPropagation();
      wm.close(id);
    } else if (e.key === 'Tab' && ref.current) {
      containTab(e, ref.current);
    }
  };

  const onTitlePointerDown = (e: PointerEvent) => {
    const el = ref.current;
    const desk = el?.offsetParent as HTMLElement | null;
    if (!el || !desk || e.button !== 0 || (e.target as HTMLElement).closest('button')) return;
    e.preventDefault();
    const tb = e.currentTarget as HTMLElement;
    const offX = e.clientX - el.offsetLeft;
    const offY = e.clientY - el.offsetTop;
    tb.setPointerCapture(e.pointerId);
    tb.classList.add('dragging');
    const move = (ev: globalThis.PointerEvent) => {
      const p = clampToDesk(ev.clientX - offX, ev.clientY - offY, el.offsetWidth, desk.clientWidth, desk.clientHeight);
      el.style.left = `${p.x}px`;
      el.style.top = `${p.y}px`;
    };
    const up = () => {
      tb.classList.remove('dragging');
      tb.removeEventListener('pointermove', move);
      tb.removeEventListener('pointerup', up);
      tb.removeEventListener('pointercancel', up);
      wm.move(id, el.offsetLeft, el.offsetTop);
    };
    tb.addEventListener('pointermove', move);
    tb.addEventListener('pointerup', up);
    tb.addEventListener('pointercancel', up);
  };

  return (
    <section
      ref={ref}
      className={`win${focused ? ' active' : ''}`}
      role="dialog"
      aria-labelledby={labelId}
      tabIndex={-1}
      data-id={id}
      hidden={minimized}
      style={{ left: x, top: y, zIndex: z, width, height, maxHeight: height ? undefined : 'calc(100% - 16px)' }}
      onKeyDown={onKeyDown}
      onPointerDownCapture={() => { if (!focused) wm.focus(id); }}
    >
      <header className={`tb${focused ? '' : ' dark'}`} onPointerDown={onTitlePointerDown}>
        <button type="button" className="back" aria-label={`Back, close ${title}`} onClick={() => wm.close(id)}>‹</button>
        <h2 id={labelId}>{title}</h2>
        <button type="button" className="min" aria-label={`Minimize ${title}`} onClick={() => wm.minimize(id)}>–</button>
        <button type="button" className="close" aria-label={`Close ${title}`} onClick={() => wm.close(id)}>×</button>
      </header>
      <div className="body">{children}</div>
    </section>
  );
}
```

```tsx
import { useCallback, useEffect, useRef } from 'react';
import { gsap } from 'gsap';
import { getProjectCount } from '@/config/os-content';
import { prefersReducedMotion } from '@/lib/motion';

export function bootLines(projectCount: number): string[] {
  return [
    'EzraOS 1.0 — Surabaya build',
    `mounting /projects ........ ${projectCount} found`,
    'starting ezra-bot ......... 1,000+ members connected',
    'market feed ............... ~14.5k req/day',
    'roblox bridge ............. 3.1M visits recorded',
    'orbit store ............... 2,700+ orders settled',
    'ready.',
  ];
}

export function Boot({ onDone }: { onDone: () => void }) {
  const logRef = useRef<HTMLDivElement>(null);
  const rootRef = useRef<HTMLDivElement>(null);
  const doneRef = useRef(false);

  const finish = useCallback(() => {
    if (doneRef.current) return;
    doneRef.current = true;
    onDone();
  }, [onDone]);

  useEffect(() => {
    if (prefersReducedMotion()) {
      finish();
      return;
    }
    const tl = gsap.timeline();
    bootLines(getProjectCount()).forEach((text, i) => {
      tl.call(() => {
        const d = document.createElement('div');
        d.textContent = text;
        logRef.current?.append(d);
      }, [], i * 0.3);
    });
    if (rootRef.current) {
      tl.to(rootRef.current, { opacity: 0, duration: 0.18, ease: 'power1.in' }, 2.0);
    }
    tl.call(finish);

    const skip = (e: Event) => { e.preventDefault(); tl.kill(); finish(); };
    window.addEventListener('keydown', skip, true);
    window.addEventListener('pointerdown', skip, true);
    return () => {
      tl.kill();
      window.removeEventListener('keydown', skip, true);
      window.removeEventListener('pointerdown', skip, true);
    };
  }, [finish]);

  if (prefersReducedMotion()) return null;

  return (
    <div id="boot" ref={rootRef} className="dark" aria-label="EzraOS is starting. Press any key or click to skip.">
      <div ref={logRef} aria-hidden="true" />
      <div className="skip">press any key to skip</div>
    </div>
  );
}
```

```tsx
/** Deterministic decorative polyline — shape only, no axis, no numbers implied (spec §2.3.3). */
export function sparkPoints(slug: string): string {
  let h = 0;
  for (const ch of slug) h = (h * 31 + ch.charCodeAt(0)) % 997;
  const pts: string[] = [];
  for (let i = 0; i < 12; i++) {
    h = (h * 131 + 7) % 997;
    pts.push(`${i * 6},${18 - (h % 14)}`);
  }
  return pts.join(' ');
}
```

```ts
import { getContact, getFeaturedCases, getLiveSystems, getShipLog } from '@/config/os-content';

export const BOT_COMMANDS = ['/projects', '/systems', '/experience', '/contact'] as const;

export interface BotAction { label: string; open: string }
export interface BotMessage { text: string; action?: BotAction }

export function botGreeting(): BotMessage {
  return {
    text: 'halo! aku Ezra Bot — versi asliku melayani 1,000+ member di Discord. coba /projects, /systems, /experience, atau /contact.',
  };
}

export function botReply(raw: string): BotMessage[] {
  const cmd = raw.trim().toLowerCase().replace(/^\//, '');
  switch (cmd) {
    case 'projects':
      return getFeaturedCases().map((c) => ({
        text: `${c.title} — ${c.metric ?? c.year}`,
        action: { label: `buka ${c.title}`, open: `case:${c.slug}` },
      }));
    case 'systems': {
      const systems = getLiveSystems();
      const live = systems.filter((s) => s.status === 'live');
      const shipped = systems.filter((s) => s.status === 'shipped');
      return [
        {
          text: `${live.length} sistem masih live: ${live.map((s) => s.name).join(', ')}. ${shipped.map((s) => s.name).join(', ')} sudah shipped.`,
        },
        { text: 'status lengkapnya ada di Monitor.', action: { label: 'buka Monitor', open: 'monitor' } },
      ];
    }
    case 'experience':
      return getShipLog().map((e) => ({ text: `${e.date} — ${e.text}` }));
    case 'contact': {
      const c = getContact();
      return [
        { text: `paling cepat lewat email: ${c.email}. kodenya di github.com/ezrabrilliant, profilnya di LinkedIn.` },
        { text: 'atau pesan resume dan kirim pesan lewat Kasir.', action: { label: 'buka Kasir', open: 'kasir' } },
      ];
    }
    default:
      return [
        { text: `aku belum paham "${raw.trim()}". coba salah satu: ${BOT_COMMANDS.join(', ')}.` },
      ];
  }
}
```

`src/apps/BotApp.tsx` (typing indicator ~600 ms per message unless reduced motion; chips stay tappable and the input typeable):

```tsx
import { useEffect, useRef, useState, type FormEvent } from 'react';
import { BOT_COMMANDS, botGreeting, botReply, type BotMessage } from './bot-replies';
import { prefersReducedMotion } from '@/lib/motion';
import { useWM } from '@/os/WindowManagerContext';
import './bot.css';

interface Entry { from: 'bot' | 'me'; msg: BotMessage }

export default function BotApp() {
  const wm = useWM();
  const [entries, setEntries] = useState<Entry[]>([]);
  const [typing, setTyping] = useState(false);
  const [input, setInput] = useState('');
  const msgsRef = useRef<HTMLDivElement>(null);
  const queueRef = useRef<Promise<void>>(Promise.resolve());
  const aliveRef = useRef(true);

  useEffect(() => () => { aliveRef.current = false; }, []);
  useEffect(() => { msgsRef.current?.scrollTo(0, msgsRef.current.scrollHeight); }, [entries, typing]);

  const say = (msgs: BotMessage[]) => {
    const delay = prefersReducedMotion() ? 0 : 600;
    for (const msg of msgs) {
      queueRef.current = queueRef.current.then(async () => {
        if (!aliveRef.current) return;
        setTyping(true);
        await new Promise((r) => setTimeout(r, delay));
        if (!aliveRef.current) return;
        setTyping(false);
        setEntries((prev) => [...prev, { from: 'bot', msg }]);
      });
    }
  };

  useEffect(() => { say([botGreeting()]); /* greet once */ // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);
```

```ts
export interface CmdResult { output: string; clear?: boolean }

const pad = (s: string, n: number) => s + ' '.repeat(Math.max(1, n - s.length));

const CMDS: Record<string, () => CmdResult> = {
  help: () => ({
```

```tsx
import { useRef, useState, type KeyboardEvent } from 'react';
import { runCommand } from './terminal-commands';
import './terminal.css';

const PS = 'ezra@ezraos:~$';

export default function TerminalApp() {
  const [lines, setLines] = useState<string[]>(['EzraOS terminal. type help to see what it knows.']);
  const [input, setInput] = useState('');
  const histRef = useRef<string[]>([]);
  const hiRef = useRef(0);
  const termRef = useRef<HTMLDivElement>(null);
  const inputRef = useRef<HTMLInputElement>(null);

  const run = (raw: string) => {
    const echoed = `${PS} ${raw}`;
    const cmd = raw.trim();
    if (!cmd) { setLines((p) => [...p, echoed]); return; }
    histRef.current.push(cmd);
    hiRef.current = histRef.current.length;
    const res = runCommand(cmd);
    setLines((p) => (res.clear ? [] : [...p, echoed, ...(res.output ? [res.output] : [])]));
    requestAnimationFrame(() => termRef.current?.scrollTo(0, termRef.current.scrollHeight));
  };

  const onKeyDown = (e: KeyboardEvent<HTMLInputElement>) => {
    const hist = histRef.current;
    if (e.key === 'Enter') {
      run(input);
      setInput('');
    } else if (e.key === 'ArrowUp' && hist.length) {
      e.preventDefault();
      hiRef.current = Math.max(0, hiRef.current - 1);
      setInput(hist[hiRef.current]);
    } else if (e.key === 'ArrowDown' && hist.length) {
      e.preventDefault();
      hiRef.current = Math.min(hist.length, hiRef.current + 1);
      setInput(hist[hiRef.current] ?? '');
    }
  };

  return (
    <div className="term dark" ref={termRef}
      onClick={(e) => {
        if (!(e.target as HTMLElement).closest('a, input') && !String(getSelection())) {
          inputRef.current?.focus({ preventScroll: true });
        }
      }}>
      <div role="log" aria-live="polite">
        {lines.map((l, i) => <div key={i} className="o">{l}</div>)}
      </div>
      <label className="line">
        <span className="ps">{PS}</span>
        <input ref={inputRef} className="tin" type="text" value={input}
          onChange={(e) => setInput(e.target.value)} onKeyDown={onKeyDown}
          aria-label="Terminal command" autoComplete="off" autoCapitalize="off"
          autoCorrect="off" spellCheck={false} />
      </label>
    </div>
  );
}
```

```ts
export const RECEIPT_WIDTH = 40;

export interface ReceiptItem { name: string; detail: string[] }

const line = (ch: string) => ch.repeat(RECEIPT_WIDTH);
const center = (s: string) => ' '.repeat(Math.max(0, Math.floor((RECEIPT_WIDTH - s.length) / 2))) + s;
const lr = (l: string, r: string) => l + ' '.repeat(Math.max(1, RECEIPT_WIDTH - l.length - r.length)) + r;

export function wibStamp(d: Date): string {
  const parts = Object.fromEntries(
    new Intl.DateTimeFormat('en-GB', {
      timeZone: 'Asia/Jakarta', day: '2-digit', month: '2-digit', year: 'numeric',
      hour: '2-digit', minute: '2-digit', hour12: false,
    }).formatToParts(d).map((p) => [p.type, p.value]),
  );
  return `${parts.day}/${parts.month}/${parts.year} ${parts.hour}:${parts.minute} WIB`;
}

export function buildReceipt(opts: { orderNo: number; stamp: string; items: ReceiptItem[] }): string {
  const rows = [
    center('EZRAOS KASIR'),
    center('Surabaya, ID'),
    line('-'),
    lr(`No. ${String(opts.orderNo).padStart(4, '0')}`, opts.stamp),
    lr('Kasir', 'ezra-bot'),
    line('-'),
  ];
  for (const item of opts.items) {
    rows.push(lr(`1x ${item.name}`, 'Rp 0'));
    for (const d of item.detail) rows.push(`   ${d}`);
  }
  rows.push(
    line('-'),
    lr('ITEMS', String(opts.items.length)),
    lr('TOTAL', 'Rp 0'),
    lr('STATUS', 'LUNAS'),
    '',
    center('TERIMA KASIH'),
  );
  return rows.join('\n');
}
```

```ts
export interface Rect { l: number; t: number; r: number; b: number }

export const FLEE_RADIUS = 90;
export const FLEE_COOLDOWN_MS = 900;
export const CATCHES_TO_OPEN = 3;

export function overlaps(a: Rect, b: Rect): boolean {
  return a.l < b.r && a.r > b.l && a.t < b.b && a.b > b.t;
}

export interface FreeSpotOpts {
  deskW: number; deskH: number; iconW: number; iconH: number;
  obstacles: Rect[];
  avoid?: { x: number; y: number };
  random?: () => number;
}

/**
 * Pick a landing spot: inside the desk with an 8px margin, a short dart away from
 * the pointer (240–520px) rather than a cross-screen teleport, avoiding obstacles.
 * Constraint relaxation over 120 tries guarantees termination (mockup-validated).
 */
export function freeSpot(o: FreeSpotOpts): { x: number; y: number } {
  const rnd = o.random ?? Math.random;
  let spot = {
    x: Math.max(8, o.deskW - o.iconW - 40),
    y: Math.max(8, o.deskH - o.iconH - 30),
  };
  for (let i = 0; i < 120; i++) {
    const x = 8 + rnd() * Math.max(1, o.deskW - o.iconW - 16);
    const y = 8 + rnd() * Math.max(1, o.deskH - o.iconH - 16);
    if (o.avoid) {
      const dist = Math.hypot(x + o.iconW / 2 - o.avoid.x, y + o.iconH / 2 - o.avoid.y);
      if (dist < 240 || (i < 70 && dist > 520)) continue;
    }
    spot = { x: Math.round(x), y: Math.round(y) };
    const box: Rect = { l: x, t: y, r: x + o.iconW, b: y + o.iconH };
    if (i < 90 && o.obstacles.some((ob) => overlaps(box, ob))) continue;
    return spot;
  }
  return spot;
}

/** Phone-mode tap rule (spec §2.4): no hover on touch, so it hops per tap; 3rd tap opens. */
export function petakTapAction(tapCount: number, reducedMotion: boolean): 'open' | 'hop' {
  if (reducedMotion) return 'open';
  return tapCount >= CATCHES_TO_OPEN ? 'open' : 'hop';
}
```

```tsx
import { useEffect, useRef, useState, type MouseEvent } from 'react';
import { gsap } from 'gsap';
import { CATCHES_TO_OPEN, FLEE_COOLDOWN_MS, FLEE_RADIUS, freeSpot, type Rect } from '@/apps/petak-flee';
import { prefersReducedMotion } from '@/lib/motion';
import { GLYPHS } from './icons';
import { useWM } from './WindowManagerContext';

function rectOf(el: Element, desk: Element, pad = 0): Rect {
  const d = desk.getBoundingClientRect();
  const r = el.getBoundingClientRect();
  return { l: r.left - d.left - pad, t: r.top - d.top - pad, r: r.right - d.left + pad, b: r.bottom - d.top + pad };
}

export function PetakIcon() {
  const wm = useWM();
  const ref = useRef<HTMLButtonElement>(null);
  const [catches, setCatches] = useState(0);
  const [caught, setCaught] = useState(false);
  const fleeingRef = useRef(false);
  const coolRef = useRef(0);

  const obstacles = (): Rect[] => {
    const desk = ref.current?.closest('#desk');
    if (!desk) return [];
    const list: Rect[] = [];
    const col = desk.querySelector('.icon-col');
    if (col) list.push(rectOf(col, desk, 10));
    for (const win of desk.querySelectorAll('.win:not([hidden])')) list.push(rectOf(win, desk, 8));
    return list;
  };

  // initial resting place: bottom-right corner of the desk
  useEffect(() => {
    const el = ref.current;
    const desk = el?.closest('#desk') as HTMLElement | null;
    if (!el || !desk) return;
    el.style.left = `${Math.max(8, desk.clientWidth - el.offsetWidth - 48)}px`;
    el.style.top = `${Math.max(8, desk.clientHeight - el.offsetHeight - 36)}px`;
  }, []);

  // the chase — pointer-only, never under reduced motion or after being caught
  useEffect(() => {
    if (caught || prefersReducedMotion()) return;
    const onMove = (e: PointerEvent) => {
      const el = ref.current;
      const desk = el?.closest('#desk') as HTMLElement | null;
      if (!el || !desk || e.pointerType === 'touch' || fleeingRef.current) return;
      if (performance.now() < coolRef.current) return;
      const r = el.getBoundingClientRect();
      const dist = Math.hypot(e.clientX - (r.left + r.width / 2), e.clientY - (r.top + r.height / 2));
      if (dist >= FLEE_RADIUS) return;
      const d = desk.getBoundingClientRect();
      const spot = freeSpot({
        deskW: desk.clientWidth, deskH: desk.clientHeight,
        iconW: el.offsetWidth, iconH: el.offsetHeight,
        obstacles: obstacles(), avoid: { x: e.clientX - d.left, y: e.clientY - d.top },
      });
      fleeingRef.current = true;
      gsap.to(el, {
        left: spot.x, top: spot.y, duration: 0.18, ease: 'power3.out',
        onComplete: () => { fleeingRef.current = false; coolRef.current = performance.now() + FLEE_COOLDOWN_MS; },
      });
    };
    document.addEventListener('pointermove', onMove);
    return () => document.removeEventListener('pointermove', onMove);
  }, [caught]);

  const openWindow = (opener: HTMLElement) => {
    setCaught(true);
    wm.open('petak', opener);
  };

  const onClick = (e: MouseEvent<HTMLButtonElement>) => {
    const el = e.currentTarget;
    // keyboard (detail 0) and reduced motion open directly — the chase is a pointer game
    if (e.detail === 0 || prefersReducedMotion() || caught) {
      openWindow(el);
      return;
    }
    const next = catches + 1;
    setCatches(next);
    if (next >= CATCHES_TO_OPEN) {
      openWindow(el);
    } else {
      coolRef.current = 0; // no breather after a hit — it panics
      const desk = el.closest('#desk') as HTMLElement;
      const d = desk.getBoundingClientRect();
      const spot = freeSpot({
        deskW: desk.clientWidth, deskH: desk.clientHeight,
        iconW: el.offsetWidth, iconH: el.offsetHeight,
        obstacles: obstacles(), avoid: { x: e.clientX - d.left, y: e.clientY - d.top },
      });
      gsap.to(el, { left: spot.x, top: spot.y, duration: 0.18, ease: 'power3.out' });
    }
  };

  const showCounter = catches > 0 && !caught;
  return (
    <>
      <button ref={ref} type="button" className="icon petak" onClick={onClick}>
        <span className="tile">{GLYPHS.petak}</span>
        <span className="lbl">Petak Umpet</span>
      </button>
      <div id="counter" role="status" hidden={!showCounter}>
        {`tangkap dia: ${catches}/${CATCHES_TO_OPEN}`}
      </div>
    </>
  );
```

```ts
import { useSyncExternalStore } from 'react';

const QUERIES = ['(max-width: 767.98px)', '(hover: none) and (pointer: coarse)'];

function subscribe(onChange: () => void): () => void {
  const lists = QUERIES.map((q) => window.matchMedia(q));
  for (const l of lists) l.addEventListener('change', onChange);
  return () => { for (const l of lists) l.removeEventListener('change', onChange); };
}

function snapshot(): boolean {
  return QUERIES.some((q) => window.matchMedia(q).matches);
}

/** Phone-OS mode (spec §2.4): width < 768px or a touch-only pointer. */
export function usePhoneMode(): boolean {
  return useSyncExternalStore(subscribe, snapshot, () => false);
}
```

## Deliberately deferred (with reasons)

- **"EzraOS" dropdown menu with an "About Ezra" item (spec §2.2)** — implemented as one direct menu-bar button (a one-item dropdown is worse keyboard UX than a button). The window itself carries everything the spec puts in "About Ezra": short bio, education (via the ship log), contact, and the shortcut listing. If Ezra wants the literal dropdown, it slots into `MenuBar.tsx` without touching anything else.
- **`shipLog` Bot copy vs. spec's "one line per event" from experience/education** — implemented as a curated `shipLog` data array in `portfolio.ts` (spec §6 lists it as a content addition) whose entries restate existing config facts; deriving prose from `experience` objects programmatically produced worse copy.
- **Close/minimize animations are instant** (open keeps the 150 ms GSAP snap). "Well under 200 ms" is satisfied trivially, reduced-motion behavior is identical by construction, and React unmount + exit tween adds real complexity for a 120 ms effect. Revisit only if Ezra misses it.
- **Terminal easter eggs** — spec says "allowed", not required. The command table in `terminal-commands.ts` makes adding one a two-line change later.
- **Build-time pre-rendering of app content** — the spec offers pre-render OR `<noscript>`; the `<noscript>` block (Task 4) is the chosen path. Full SSR/prerender would touch the deployment, which is frozen.
- **PageSpeed ≥ 95 verification** — fonts are subset to 6 weights total and preloaded, GSAP tree-shaken, apps code-split (Tasks 4/5/15), but the actual Lighthouse run needs the deployed HTTPS origin; run it after the first deploy and treat a miss as a bug.
- **Sub-360 px widths and IE-era browsers** — spec sets the floor at 360 px; nothing below it is tested.
